# Пробный импорт одного VLESS-сервера

Файл onexray-vless-template.json подготовлен по первому VLESS outbound присланного service_core.json. Это шаблон одного сервера, не полный перенос Karing. Реальные параметры доступа не включены. Сначала заполните значения локально, затем импортируйте.

## Что заменить

Откройте оригинальный локальный конфиг Karing и найдите тот же первый объект outbounds с type=vless. В шаблоне замените:

| Исходное поле Karing | Поле шаблона OneXray |
| --- | --- |
| server | outbounds[0].settings.vnext[0].address |
| uuid | outbounds[0].settings.vnext[0].users[0].id |
| tls.server_name | outbounds[0].streamSettings.realitySettings.serverName |
| tls.reality.public_key | outbounds[0].streamSettings.realitySettings.password |
| tls.reality.short_id | outbounds[0].streamSettings.realitySettings.shortId |

В realitySettings.password нужен **публичный ключ REALITY**, несмотря на название password. Приватный ключ сюда не вставлять. Если исходный short_id — пустая строка, сохраните пустую строку и в shortId; не придумывайте значение. SNI/serverName может отличаться от адреса сервера, копируйте его отдельно.

Числовой port=2080, flow=xtls-rprx-vision и fingerprint=edge перенесены из присланного файла. Сверьте их с оригиналом, если тоже заменяли при обезличивании. network=raw означает TCP в текущем формате Xray. allowInsecure/отключение TLS-проверок не добавлялись.

Это не обратимое раскрытие заглушек: оригинальные значения можно взять только из вашего локального Karing/данных провайдера. Отправлять заполненный файл в чат не требуется.

## Как импортировать

1. Сохраните заполненный JSON в UTF-8. Строки должны оставаться в двойных кавычках, port — числом.
2. В OneXray откройте Servers / Серверы → Add servers / Добавить → Import file / Импорт файла.
3. Выберите заполненный onexray-vless-template.json. Альтернатива: Manual add / ручное добавление и вставка всего JSON с корневым outbounds.
4. Выберите добавленный Veilor - VLESS test на экране Connect. Это обычный сервер, импортировать через Raw JSON не нужно.
5. Перед проверкой выключите подключение в Karing, чтобы два VPN не меняли маршруты одновременно. На Windows выполните выбор исходящего сетевого интерфейса, если OneXray его запрашивает; выберите подключённый Wi-Fi/Ethernet, не виртуальный адаптер Karing.
6. Подключитесь, проверьте открытие сайта и внешний IP. Наличие добавленного сервера/пинга само по себе не доказывает работу туннеля.
7. Отключите OneXray и убедитесь, что обычный интернет работает. При ошибке сохраните её текст, скрыв адреса/идентификаторы.

DNS, TUN и маршрутизацию на этом этапе задаёт OneXray. Правила Karing, 73 .srs, группы автоматического выбора и остальные 45 серверов не переносились. Поведение распределения трафика поэтому пока не сравнивается.

## Что уже проверено

JSON успешно разбирается; содержит ровно один VLESS outbound. Порт, flow и fingerprint сверены с обезличенным источником. Проверка Xray core/подключения **не выполнялась**: публичный ключ, shortId, UUID, адрес и SNI намеренно заменены. До заполнения шаблон может быть отклонён импортёром; это ожидаемо.
