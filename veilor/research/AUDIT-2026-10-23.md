## Как устроена сборка Windows

Основание: source/readme/FIRST_RUN.md, source/build_scripts/README.md, source/.github/workflows/build.yml, source/build_scripts/app/windows.py, source/windows/app.cmake, libXray/build/app/windows.py, Vole/scripts/README.md.

- Flutter/Dart: UI и логика приложения. pubspec требует Dart >=3.13.0 <4.0.0.
- libXray: Go/CGo библиотека libXray.dll и отдельный OneXrayCore.exe. go.mod требует Go 1.27.2. Windows DLL компилируется через gcc.exe/g++.exe; нужны совместимые C-инструменты, например предусмотренный CI LLVM-MinGW.
- EXE/ZIP: штатный путь использует Xray native TUN и Wintun 0.14.1 из официального архива.
- MSIX: Vole UWP Provider + Session Host, Xray работает через внутренний SOCKS.
- Текущая упаковка обоих вариантов включает Vole DLL и оба host EXE. Просто исключать Vole из сборки EXE без отдельной правки нельзя.
- Vole собирается из Rust с MSVC/Windows SDK; его скрипт ищет Visual Studio через vswhere. Среди требований также CMake, Perl и libclang.
- В комплект входят GeoData, сгенерированные FFI и локализации; свежего clone без подготовки этих файлов недостаточно.
- Для первого локального Debug EXE не нужны Store-ключи и аккаунт издателя. Для готовых EXE/ZIP штатная упаковка добавляет Fastforge, EXE — Inno Setup. Для MSIX нужна отдельно проверяемая установка подписанного пакета.

## Что действительно запускалось

1. Flutter doctor: Flutter 3.44.4, Dart 3.12.2; Windows поддерживается, Visual Studio не обнаружена. Лог: flutter-doctor.log.
2. Flutter pub get с изолированным PUB_CACHE: остановился на требовании Dart >=3.13.0. Лог: flutter-pub-get.log. Зависимости приложения не разрешены.
3. Python unittest discover для source/build_scripts/tests: 35 тестов, OK. Лог: build-script-tests.log. Это тесты скриптов с подменой внешних сборщиков, не компиляция Flutter/VPN.
4. libXray build/main.py windows: остановился при вызове отсутствующего go, WinError 2. Лог: libxray-build.log.
5. uv run --project scripts --locked vole-scripts build windows --backend uwp: окружение Python подготовлено, сборка завершилась WinError 2. Лог: vole-build.log. В системе не найден vswhere, а код подготовки MSVC вызывает именно его; cargo/rustc также отсутствуют в PATH. До компиляции Vole проверка не дошла.
6. git diff --check: OneXray, libXray, Vole — без ошибок; git status --short для этих checkout пустой.

Скрипты оболочки выводили логи после вызовов, поэтому код завершения оболочки не равен коду завершения вложенного компилятора. Результаты выше определены по журналам. Успешная сборка, запуск собственного бинарника, системный VPN, DNS и отсутствие утечек НЕ подтверждены.

Установленные VPN-клиенты, их реальные профили и соединения не изменялись. Исходники Karing/Veilor не изменялись. Commit/push не выполнялись.
