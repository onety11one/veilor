# Сохранённые результаты исследования

AUDIT-2026-10-23.md и BUILD-PROGRESS-2026-10-23.md сохранены из исходного локального workspace как исторические отчёты. Их абсолютные пути и названия журналов описывают ту машину и структуру каталогов, а не переносимую конфигурацию проекта.

Текущие команды и точка продолжения — [BUILD-WINDOWS.md](../BUILD-WINDOWS.md) и [HANDOFF.md](../HANDOFF.md). При конфликте с промежуточными планами приоритет у HANDOFF.

[build-evidence.json](build-evidence.json) содержит результаты команд, версии и хэши собранных native-файлов. Журналы из него сохранены в [evidence/](evidence/) под расширением .txt вместо .log. Это проверка исходного OneXray без реализации дизайна Veilor; самостоятельная сборка всего приложения и работа VPN ещё не подтверждены.

Большие артефакты, SDK/кэши и реальные конфиги намеренно исключены. Восстановление исходников зависимостей выполняется по [manifest](../upstream-sources.lock.json); upstream license-файлы находятся в соответствующих checkout. Не заменять отсутствующие артефакты DLL из установленного приложения: это лишит проверку смысла сборки из исходников.
