# Адаптер чтения показателей ядра

Независимый Dart-пакет без внешних зависимостей. Не подключён к Flutter-приложению: его можно проверять, пока исходный пакет `vpn_service` отсутствует.

Поддерживает только `GET /version` и `GET /connections` локального HTTP API Karing. Возвращает версию, память, время сессии, входящие/исходящие соединения, скорости и накопленный трафик. Детали отдельных соединений не сохраняются. Наличие ответа API не означает, что VPN подключён.

Поля сопоставлены с текущим `lib/screens/net_connections_screen.dart`: память — `memory`, основной счётчик — `connectionsInCount`, время — `startTime`. Отсутствующие/неверные измерения возвращаются как `null`; они не подменяются нулём или длиной массива соединений. Время без часового пояса и отрицательная длительность недоступны. Единицы скорости соответствуют исходным байтам в секунду; форматирование относится к будущему UI.

Клиент принимает адрес и секрет явно. Разрешены только HTTP origin на localhost, 127.0.0.1 и ::1. Системный HTTP-прокси и редиректы отключены. Каждый запрос ограничен временем и размером ответа; `close()` отменяет активные запросы. Ошибки не включают тело ответа и секрет. Автоопроса, команд изменения VPN и чтения конфигурации в библиотеке нет.

Из папки пакета, используя доступный Dart SDK:

```powershell
dart run test/read_only_test.dart
dart analyze lib test tool
```

Ручная проверка на **уже работающем** локальном Karing (с указанием пути к его конфигурации):

```powershell
dart run tool/probe_local.dart <путь-к-service_core.json>
```

Probe читает адрес/секрет в памяти, выполняет два GET и выводит только версию и агрегированные показатели. Не выводит настройки, адрес контроллера, серверы, секрет и данные отдельных соединений. Если ядро недоступно, он завершится с ошибкой, не запуская VPN.

Проверка установленной версии 1.2.25+2802 не доказывает совместимость с отсутствующим ядром 1.14.0 для текущей исходной базы 1.2.26+2908. Восстановление запуска, конфигуратора, DNS, маршрутизации и полного набора функций — следующие отдельные этапы.
