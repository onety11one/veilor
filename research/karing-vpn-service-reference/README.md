# Найденные исходники обвязки VPN Karing

Здесь собраны **48 исторических Dart-файлов** для изучения: обвязка VPN, генератор конфигурации, клиент Clash API и вспомогательные исходники. Они не подключены к рабочему приложению.

Это **не полный пакет `vpn-service`**. Найденный `lib/app/local_services/vpn_service.dart` сам зависит от `package:vpn_service/...`. Исходники этого внешнего пакета здесь отсутствуют.

## С чего начать

1. [VPNService — подготовка конфигурации, запуск, остановка и состояние](lib/app/local_services/vpn_service.dart).
2. [SingboxConfigBuilder — формирование конфигурации ядра](lib/app/utils/singbox_config_builder.dart).
3. [ClashApi — взаимодействие с API ядра](lib/app/utils/clash_api.dart).
4. [ProxyConfUtils — вспомогательная обработка конфигураций](lib/app/utils/proxy_conf_utils.dart).
5. [PathUtils — расположение файлов и компонентов](lib/app/utils/path_utils.dart).

Прочие файлы в `lib/app/utils` сохранены как дополнительный исторический контекст. Это не полностью замкнутый граф зависимостей.

- Пути относительно этой папки соответствуют исходным путям внутри старого репозитория.
- [Манифест](source-manifest.json) содержит список файлов, размеры и SHA-256 исходных байтов, а также отсутствующие в этом историческом commit файлы из нашей проверки.

Файлы сохранены без редактирования. Атрибут `-text` отключает преобразование переводов строк для архивных Dart-файлов, чтобы сохранить точные байты.

## Ограничения

Исходники относятся к 2025 году. Рабочая база Veilor использует Karing 1.2.26, а исследованный установленный выпуск — 1.2.25+2802. Совместимость исторического кода с ними не доказана. Не следует массово переносить эти файлы в активный `lib` и считать приложение восстановленным.

В коллекции нет готового VPN-сервиса, бинарных файлов установленного Karing, личных профилей, реквизитов подписок и конфигурации пользователя.

Авторство исходного кода принадлежит его авторам. Лицензионное уведомление исходного commit сохранено в [UPSTREAM-LICENSE.md](UPSTREAM-LICENSE.md).
